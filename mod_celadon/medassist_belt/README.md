## MedAssist Belt

ID мода: CELADON_MEDASSIST_BELT

### Описание мода

Автоматическая поясная аптечка, которая отслеживает состояние носителя и автоматически вводит медицинские препараты при критическом состоянии.

**Функционал:**
- Автоматический мониторинг здоровья через processing loop (каждую секунду)
- Инъекция медикаментов при критическом состоянии (задержка 5 сек, кулдаун 60 сек)
- При смерти носителя:
  - Однократная инъекция 2u формальдегида (консервация органов)
  - Периодические алерты каждые 1-3 минуты
  - Runechat сообщение "КРИТИЧЕСКОЕ СОСТОЯНИЕ ПАЦИЕНТА!"

**Визуальные состояния:**
- Устройства меняют иконку при опустошении
- Icon states: `autoinjector_nt`, `autoinjector_copy`, `autoinjector_handcraft`
- Empty states: `autoinjector_nt_empty`, `autoinjector_copy_empty`, `autoinjector_handcraft_empty`

**Архитектура:**

**Базовый класс `/obj/item/medassist_device`:**
- Содержит только общую логику (processing, equipped/dropped, иконки)
- Не имеет переменных для доз, реагентов, формальдегида
- Абстрактный метод `handle_wearer_state()` для подклассов

**Варианты:**

**1. MedAssist Mk.II (Nanotrasen) - ПРЕМИУМ**
- Path: `/obj/item/medassist_device/proto`
- Дозы: 3 по 17u
- Реагенты: Atropine (12u), Salbutamol (12u), Tricordrazine (27u)
  - Сбалансировано под скорости метаболизма (0.1u/0.1u/0.4u за тик)
  - Atropine: лечит ВСЁ в крите (-2/-2/-2/-5 урона), ~2 мин
  - Salbutamol: окси урон (-3 REM), ~2 мин
  - Tricordrazine: универсальный хил всего, ~1.1 мин
- Формальдегид: ✅ (2u при смерти)
- Перезарядка: ❌ (одноразовое устройство)
- Качество: Профессиональное, продвинутые медикаменты

**2. MedAssist Copy - КУСТАРНАЯ РЕПЛИКА**
- Path: `/obj/item/medassist_device/proto/copy`
- Наследует от proto, меняет только реагенты и количество доз
- Дозы: 4 по 17u (увеличенный резервуар)
- Реагенты: Epinephrine (20u), Bicaridine (24u), Kelotane (24u)
- Формальдегид: ✅ (2u при смерти)
- Перезарядка: ❌ (одноразовое устройство)
- Качество: Базовые реагенты, больше доз

**3. MedAssist Handcraft - САМОДЕЛЬНАЯ (ПЕРЕЗАРЯЖАЕМАЯ)**
- Path: `/obj/item/medassist_device/handcraft`
- Отдельная ветка, не наследует от proto
- Дозы: **ОДНА НА VIAL** (вводит ВСЁ содержимое vial разом)
- Реагенты: **Требует ручной заправки vial'ом!**
  - Вставляется `/obj/item/reagent_containers/glass/bottle/vial/small` с любыми реагентами (30u макс)
  - Вставка: используйте vial на устройстве
  - Извлечение: используйте отвертку на устройстве
  - При крите: вводит **ВСЁ** содержимое vial'а за один раз
  - После инъекции: vial пуст, можно заменить на новый
- Формальдегид: ❌ (нет)
- Перезарядка: ✅ (замена vial - бесконечное переиспользование)
- Качество: Самодельное, перезаряжаемое через замену vial, гибкое

### Критические исправления

В ходе разработки были обнаружены и устранены **5 критических ошибок**:

**1. Бесконечный кулдаун при недостатке реагентов**
- Проблема: Кулдаун запускался даже если инъекция не удавалась
- Решение: `addtimer()` перенесён внутрь `if(reagents.total_volume >= injection_amount)`
- Результат: Устройство сбрасывает `on_cooldown = FALSE` при неудаче

**2. Застывший флаг vial_used**
- Проблема: Если инъекция отменялась (цель выздоровела/умерла), флаг не сбрасывался
- Решение: Добавлен `vial_used = FALSE` перед каждым `return` в `attempt_injection()`
- Результат: Handcraft может попробовать снова при восстановлении условий

**3. Спам-бомба при отсутствии формальдегида**
- Проблема: `next_death_alert = 0` при `has_formaldehyde = FALSE` вызывал спам каждый тик
- Решение: Добавлена проверка `formaldehyde_injected &&` перед проверкой времени
- Результат: Алерты срабатывают только если формальдегид был введён

**4. Дублирование vial через forceMove**
- Проблема: `forceMove()` + `put_in_hands()` без проверки результата → vial падал на пол, переменная обнулялась
- Решение: Заменено на `if(user.put_in_hands(loaded_vial))` с проверкой результата
- Результат: Vial остаётся в устройстве если у игрока заняты руки

**5. Полная иконка у пустого handcraft при спавне**
- Проблема: `update_icon_state()` не вызывался при инициализации
- Решение: Добавлен `Initialize()` с вызовом `update_appearance()`
- Результат: Handcraft спавнится с иконкой `_empty`

### Технические особенности

**Магические числа устранены:**
- `create_reagents(51, INJECTABLE)` → `create_reagents(initial(doses_remaining) * initial(injection_amount), INJECTABLE)`
- Автоматический расчёт ёмкости: Mk.II = 3×17 = 51u, Copy = 4×17 = 68u

**Одноразовость после полного использования:**
- Proto/Copy с `doses_remaining <= 0 && formaldehyde_injected` не запускаются при повторном надевании
- Предотвращает спам алертов после снятия с трупа
- Флаг `formaldehyde_injected` не сбрасывается при `dropped()` (одноразовый)

**Безопасность извлечения vial:**
- Проверка результата `put_in_hands()` предотвращает потерю vial
- Vial обнуляется только при успешной передаче в руки
- Честная обратная связь: "You need a free hand to take the vial!"

**Архитектурная чистота:**
- Базовый класс: 47 строк (только общее)
- Proto: 137 строк (полная реализация)
- Copy: 18 строк (наследует всё от proto)
- Handcraft: 110 строк (независимая vial-система)
- Итого: 330 строк для 3 устройств с 0% дублирования
