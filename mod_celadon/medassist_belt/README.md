## MedAssist Belt

ID мода: CELADON_MEDASSIST_BELT

### Описание мода

Автоматическая поясная аптечка, которая отслеживает состояние носителя и автоматически вводит медицинские препараты при критическом состоянии.

**Функционал:**
- Автоматический мониторинг здоровья через processing loop (каждую секунду)
- Инъекция медикаментов при критическом состоянии (задержка 5 сек, кулдаун 60 сек)
- При смерти носителя:
  - Однократная инъекция 2u формальдегида (консервация органов)
  - Периодические алерты каждые 1-3 минуты
  - Runechat сообщение "КРИТИЧЕСКОЕ СОСТОЯНИЕ ПАЦИЕНТА!"

**Визуальные состояния:**
- Устройства меняют иконку при опустошении
- Icon states: `autoinjector_nt`, `autoinjector_copy`, `autoinjector_handcraft`
- Empty states: `autoinjector_nt_empty`, `autoinjector_copy_empty`, `autoinjector_handcraft_empty`

**Архитектура:**

**Базовый класс `/obj/item/medassist_device`:**
- Содержит только общую логику (processing, equipped/dropped, иконки)
- Не имеет переменных для доз, реагентов, формальдегида
- Абстрактный метод `handle_wearer_state()` для подклассов

**Варианты:**

**1. MedAssist Mk.II (Nanotrasen) - ПРЕМИУМ**
- Path: `/obj/item/medassist_device/proto`
- Дозы: 3 по 17u
- Реагенты: Atropine (12u), Salbutamol (12u), Tricordrazine (27u)
  - Сбалансировано под скорости метаболизма (0.1u/0.1u/0.4u за тик)
  - Atropine: лечит ВСЁ в крите (-2/-2/-2/-5 урона), ~2 мин
  - Salbutamol: окси урон (-3 REM), ~2 мин
  - Tricordrazine: универсальный хил всего, ~1.1 мин
- Формальдегид: ✅ (2u при смерти)
- Качество: Профессиональное, продвинутые медикаменты

**2. MedAssist Copy - КУСТАРНАЯ РЕПЛИКА**
- Path: `/obj/item/medassist_device/proto/copy`
- Наследует от proto, меняет только реагенты и количество доз
- Дозы: 4 по 17u (увеличенный резервуар)
- Реагенты: Epinephrine (20u), Bicaridine (24u), Kelotane (24u)
- Формальдегид: ✅ (2u при смерти)
- Качество: Базовые реагенты, больше доз

**3. MedAssist Handcraft - САМОДЕЛЬНАЯ (ПЕРЕЗАРЯЖАЕМАЯ)**
- Path: `/obj/item/medassist_device/handcraft`
- Отдельная ветка, не наследует от proto
- Дозы: **ОДНА НА VIAL** (вводит ВСЁ содержимое vial разом)
- Реагенты: **Требует ручной заправки vial'ом!**
  - Вставляется `/obj/item/reagent_containers/glass/bottle/vial/small` с любыми реагентами (30u макс)
  - Вставка: используйте vial на устройстве
  - Извлечение: используйте отвертку на устройстве
  - При крите: вводит **ВСЁ** содержимое vial'а за один раз
  - После инъекции: vial пуст, можно заменить на новый
- Кулдаун: ❌ (нет - одна инъекция на vial)
- Формальдегид: ❌ (нет)
- Качество: Самодельное, перезаряжаемое через замену vial, гибкое

- 2x Cable Restraints

- 2x Metal

- Wirecutter
