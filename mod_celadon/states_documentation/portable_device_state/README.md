# Документация состояний UI для портативных устройств

## Описание

Эта папка содержит документацию по состояниям UI, созданным командой CeladonSS13 для улучшения пользовательского опыта с портативными устройствами.

## Доступные состояния

### `portable_device_state`

**Файл**: `code/modules/tgui/states/portable_device.dm`

**Описание**: Универсальное состояние для портативных устройств, которое позволяет использовать UI в лежачем положении.

**Логика**:
- Проверяет наличие предмета в инвентаре пользователя
- Проверяет сознание пользователя (`user.stat == CONSCIOUS`)
- Возвращает `UI_INTERACTIVE` для лежачих, но сознательных персонажей

**Использование**:
```dm
/obj/item/your_device/ui_state(mob/user)
	return GLOB.portable_device_state
```

**Подходит для**:
- Рации (`/obj/item/radio`)
- PDA (`/obj/item/pda`)
- Планшеты
- Портативные сканеры
- Гарнитуры
- Любые портативные устройства с UI

## Как использовать

### 1. Для существующих предметов

Добавьте в ваш предмет:

```dm
/obj/item/your_device/ui_state(mob/user)
	return GLOB.portable_device_state
```

### 2. Для новых предметов

При создании нового портативного устройства с UI, используйте `portable_device_state` вместо `inventory_state`:

```dm
// Вместо этого:
/obj/item/new_device/ui_state(mob/user)
	return GLOB.inventory_state

// Используйте это:
/obj/item/new_device/ui_state(mob/user)
	return GLOB.portable_device_state
```

## Важные замечания

### Когда использовать `portable_device_state`:
- Портативные устройства (рации, PDA, планшеты)
- Устройства, которые должны работать в лежачем положении
- Предметы, которые пользователь держит в руках или носит

### Когда НЕ использовать `portable_device_state`:
- Стационарные устройства (компьютеры, консоли)
- Устройства, требующие активного взаимодействия
- Предметы, которые нельзя использовать лежа

## Игровая логика

### Состояния пользователя:
- **Сознательный и лежачий**: UI активен
- **Сознательный и стоящий**: UI активен  
- **Без сознания**: UI закрыт
- **Мертв**: UI закрыт

### Проверки:
1. **Инвентарь**: Предмет должен быть у пользователя
2. **Сознание**: Пользователь должен быть в сознании
3. **Положение**: Лежачее положение разрешено

## Миграция существующего кода

Если у вас есть предметы, использующие `inventory_state`, и вы хотите разрешить их использование в лежачем положении:

### Было:
```dm
/obj/item/device/ui_state(mob/user)
	return GLOB.inventory_state
```

### Стало:
```dm
/obj/item/device/ui_state(mob/user)
	return GLOB.portable_device_state
```

## Отладка

### Проблема: UI неактивен для лежачих
**Решение**: Убедитесь, что используете `GLOB.portable_device_state`

### Проблема: UI активен без предмета
**Решение**: Проверьте, что предмет находится в инвентаре пользователя

### Проблема: UI активен для без сознания
**Решение**: Проверьте, что пользователь в сознании (`user.stat == CONSCIOUS`)
